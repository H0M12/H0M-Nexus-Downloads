## التنزيل

انتقل إلى [صفحة الإصدارات](https://github.com/H0M12/H0M-Nexus-Downloads/releases) لملفات الإصدار المتاحة. تحقّق من وصف الإصدار وبصمات `SHA256SUMS.txt` قبل الاستخدام.

| الملف | ما الذي تحصل عليه؟ |
|---|---|
| Windows x64 Portable ZIP | EXE حقيقي مع مكتباته؛ فكّ المجلد كاملًا وشغّل `H0MNexus.exe` داخله. Windows 10/11 x64. |
| Android debug APK | ملف قابل للتثبيت للاختبار، موقّع بمفتاح Debug، وليس توقيع إصدار إنتاجي. |
| Android unsigned AAB | حزمة release-variant غير موقّعة للمطور؛ ليست ملفًا للتثبيت المباشر أو النشر الجاهز. |

**هذا المستودع للتنزيلات الثنائية فقط.** لا يتضمن كود التطبيق، ولا ZIP المصدر الخاص بالمالك، ولا النسخة الشخصية الخاصة بـWindows. ملفات «Source code» التي ينشئها GitHub تلقائيًا تخص README وبيانات هذا المستودع فقط، وليست مصدر البرنامج.

## ما يفعله التطبيق

**Windows:** تشغيل فحص سريع أو فحص مسار يختاره المستخدم عبر Microsoft Defender عند توفره، ومعاينة المؤقتات القديمة قبل اختيار ملفات وتأكيد حذفها. يعيد التنظيف التحقق من لقطة الملف وهويته قبل الحذف. توجد إدارة لمدخلات بدء التشغيل الخاصة بالمستخدم `HKCU Run` مع نسخة استعادة، وأداة اختيارية لتقليل مجموعة عمل برنامج مؤهل واحد بعد موافقة صريحة. لا تُقتل البرامج أو تُعدّل خدمات النظام؛ تقليل مجموعة العمل قد يبطّئ البرنامج لاحقًا، ولا يعني توفير رام فعلية أو تسريعًا مضمونًا.

**Android:** مراجعة بيانات التطبيقات المرئية ومؤشرات صلاحياتها، ومراقبة اختيارية للتثبيت الجديد أثناء عمل الخدمة، وتنظيف كاش التطبيق نفسه أو ملفات مجلد يختاره المستخدم عبر أذونات Android الرسمية، بعد معاينة واختيار وتأكيد. مؤشرات المخاطر ليست حكمًا بوجود فيروس. لا يوجد ادعاء بمسح فيروسات شامل للجهاز، أو حذف كاش البرامج الأخرى، أو قتل جميع العمليات وتفريغ الرام.

**الشبكة والإعدادات:** قياس تنزيل فعلي عند الطلب من Cloudflare باستهلاك نحو 10 MB، مع فصل النتيجة عن عدادات محوّل الشبكة. تتوفر إرشادات Family DNS يدويًا، وليست VPN أو تغييرًا خفيًا لإعدادات الجهاز. الواجهة عربية/إنجليزية بهوية H0M أصلية.

## مهم قبل الاستخدام

هذه الحزم **غير موقّعة للإنتاج** ولا تحمل شهادة حماية مستقلة. نسخة Windows محمولة وليست Setup installer، واختبار توافق Wine ليس اختبارًا على Windows أصلي. نجح بناء Android و19 اختبار JVM، لكن الواجهة والأذونات والمراقبة وSAF لم تُختبَر على هاتف أو محاكي. يلزم اختبار أجهزة حقيقية ومراجعة الاعتماديات والأمان قبل الاستخدام الإنتاجي.

**الدفع وPro غير مفعّلين.** يوجد مدخل دفع آمن وحالة «البوابة غير جاهزة»؛ حساب التاجر وبياناته ونشر الخادم واستكمال واجهة الحساب واختبار الشراء الحقيقي ما زالت مطلوبة. لا يُفعّل اشتراك من مجرد رجوع المستخدم من صفحة دفع. بناء Windows الحالي يستخدم المتصفح عند إعداد البوابة وموافقة المستخدم؛ تضمين WebView2 ليس مفعّلًا في بناء MinGW هذا. Android يستخدم Custom Tabs عند تهيئة عنوان موثوق. لا توجد بيانات بطاقة داخل التطبيق، ولا فوترة متاجر مفعّلة، ولا تحصيل أموال في هذه النسخة.
